## Features

✅ RESTful API with auth  
✅ JWT security  
✅ Database layer  
✅ Error handling  
✅ Docker ready  
✅ Test suite  

## Quick Start

\`\`\`bash
npm install
npm run dev
\`\`\`

## API

- \`POST /auth/register\` - Register
- \`POST /auth/login\` - Login
- \`GET /api/data\` - Fetch data
- \`POST /api/data\` - Create data
- \`GET /health\` - Health check
